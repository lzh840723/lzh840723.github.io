隐私政策

生效及最后更新：2026 年 10 月 26 日

本政策说明 StoryEngine 个人本地工作流及本介绍网站如何处理信息，尤其是通过 Google OAuth 与 YouTube Data API 获得的授权及数据。

1. 使用范围

StoryEngine 由 GitHub 用户 lzh840723 维护，当前面向维护者个人使用。本网站用于公开说明应用用途，不提供用户注册、Google 登录、视频上传或书稿托管服务。本地工具与本网站的运行环境相互独立。

2. 访问哪些 Google 与 YouTube 数据

YouTube 连接仅请求 https://www.googleapis.com/auth/youtube.upload 权限，用于在用户授权的频道中上传用户选择的视频及其标题、简介和其他所需元数据。Google 授权页面可能将该权限描述为“管理您的 YouTube 视频”。

本地工作流保存 OAuth 客户端配置、访问令牌及刷新令牌；执行上传后，可保存返回的视频 ID、处理状态及上传结果以确认任务。StoryEngine 不要求用户向本网站提交 Google 密码，也不请求 Gmail、通讯录或云端硬盘的访问权限。

3. 信息的用途

授权令牌用于完成用户要求的 YouTube 上传任务，并在授权有效期内续期访问。视频与元数据用于用户选择的上传；视频 ID 和任务结果用于确认上传及避免误操作。授权本身不会自动选择视频、上传文件或改变视频可见性。

通过 Google API 获得的数据仅用于所授权的 YouTube 功能，不出售，不用于广告画像，不作为小说生成模型的输入，也不用于训练通用人工智能或机器学习模型。

4. 存储与保护

在维护者当前的本地配置中，OAuth 凭据与令牌保存在本机受限制的目录和文件中，并排除在 Git 版本控制之外。本介绍网站不接收、存储或处理这些凭据、视频或书稿。访问本机环境的人仍可能接触本地数据，使用者应保护电脑、磁盘及备份。

5. 信息共享与第三方服务

在用户要求上传时，所选择的视频、元数据及必要的授权信息会传送给 Google / YouTube，以完成身份验证和上传。视频上传后的存储、处理及可见性由 YouTube 设置及其政策决定。StoryEngine 不将 Google 授权数据分享给广告服务或其他无关第三方。

本网站由 GitHub Pages 托管；GitHub 可能按其政策处理 IP 地址等访问日志。本网站未加入独立的分析脚本、广告追踪或登录表单。第三方的处理方式请参阅 Google 隐私政策和 GitHub 隐私声明。

6. 保留、撤销与删除

本地令牌保留至使用者删除、撤销授权或令牌失效。可随时在 Google 账号的第三方连接中移除 StoryEngine 的权限，并删除本机保存的凭据、令牌和上传记录。撤销授权不会自动删除已经上传的视频；用户可在 YouTube Studio 中另行管理或删除视频。

本地文件和备份由使用者管理，维护者无法通过本介绍网站远程读取或删除这些文件。

7. Google 用户数据的有限使用

StoryEngine 对从 Google API 收到的信息的使用及转移将遵守 Google API 服务用户数据政策，包括其中的“有限使用”（Limited Use）要求。

8. 联系与政策更新

有关政策、撤销或删除的问题，请通过 GitHub 网站仓库的问题反馈联系维护者。请勿提交任何密钥、令牌或私人内容。如数据用途发生变化，将先更新本页；新增权限应重新征得使用者同意。

Google user data is used only for the authorized YouTube upload workflow. OAuth tokens are stored locally, not on this website. We do not sell Google user data, use it for advertising, or use it to train generalized AI/ML models. Access can be revoked through Google Account connections.
